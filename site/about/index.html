About Nodus Research

Nodus Research is a personal, independent open-source project developed in Spain. It is the project behind Nodus, a local-first desktop application for connecting academic sources, ideas and evidence. The project currently sells no product or service.

01 · Project and application

Two names, with two precise jobs.

The distinction is simple and applies everywhere the software is documented, cited or distributed.

The project

Nodus Research

Nodus Research is the project, website and open-source ecosystem. It publishes the documentation, source code, archived releases, citation records and the tools built around the desktop application.

Cite Nodus Research
The application

Nodus

Nodus is the downloadable desktop application for macOS, Windows and Linux. It organises work into purpose-built vaults and keeps the corpus and search indexes on the user's own computer.

03 · Principles

The promises the name stands for.

01

Local-first

Vaults, the shared Library and search indexes live on the user's computer. Nodus has no required account, subscription or project-run storage service.

02

Evidence before fluency

Claims and interpretations stay connected to their source, supporting passage and page or timestamp so that a generated answer can be checked.

03

Open source you can audit

Nodus 4 and later are published under AGPL-3.0-only. The project itself currently sells no product or service; the licence separately governs how anyone may use, modify and redistribute the code, including in commercial contexts.

04

AI remains optional

The core workspace works without AI. Model-assisted tasks start only after the user configures a provider or a local runtime such as Ollama or LM Studio.

05 · Identity and independence

One project, identified precisely.

The Latin word nodus is used in many unrelated contexts. This website identifies one specific personal software project through its domain, author, repository and DOI.

Nodus Research at nodusresearch.com is not a company, university department or academic research group. It is a personal, independent open-source software project developed in Spain.

The project is not affiliated with, sponsored by or endorsed by any university, research group, company or other software project that uses “Nodus” or a similar name. No connection should be inferred from a shared word.

The authoritative identifiers for this project are the domain nodusresearch.com, the GitHub repository Drakonis96/nodus, conceptual DOI 10.5281/zenodo.21515531, and the description “the open-source project behind Nodus”.

No affiliation is implied by a shared name. When citing or linking this project, use “Nodus Research” for the project and “Nodus” for the desktop application. Specific third-party notices are collected on the legal notice page.

06 · Short answers

About Nodus Research.

01

What is Nodus Research?

A personal, independent open-source project developed in Spain, behind the Nodus desktop application, this website, its documentation, integrations and archived releases.

02

Is Nodus Research a research group?

No. Despite the name, it is a software project rather than a university department or academic research group.

What is Nodus?

A free local-first desktop workspace for research, teaching, study and structured data, available for macOS, Windows and Linux.

Who develops Nodus?

Jorge Pérez Burgueño created the project, which is developed openly with contributions recorded in its public repository.
