# legalize-kr

대한민국 — Markdown으로 작성하고 git 저장소로 버전 관리하는 법령.

각 법령은 하나의 파일이며, 각 개정은 실제 공식 공포일을 기준으로 날짜가 기록된 commit입니다. 어떤 법령이든 `git log`를 통해 전체 이력을 확인할 수 있습니다 — 언제 제정되었는지, 어떤 조문이 변경되었는지, 어떤 규범에 의해 변경되었는지.

대한민국의 현행 법령을 공식 공포일을 기준으로 버전 관리되는 마크다운으로 발행한다. 원천 데이터는 법제처가 운영하는 국가법령정보센터(law.go.kr)와 국가법령정보 공동활용(open.law.go.kr) 오픈 API다. 이 엔진에는 한국 전용 페처(fetcher)가 없으며, 데이터는 독립된 파이프라인으로 수집되었다.

## 구성 내용

- **법령 (법률·대통령령·총리령·부령 등)** — 헌법·법률 및 그 시행령·시행규칙을 포함하는 중앙 법령
- **행정규칙 (훈령·예규·고시 등)** — 중앙행정기관의 행정규칙
- **자치법규 (조례·규칙)** — 지방자치단체의 조례 및 규칙
- **조약** — 대한민국이 체결한 조약

## 데이터 출처

- **국가법령정보센터 (National Law Information Center) — 법제처 (Ministry of Government Legislation, MOLEG)**
  - 포털: https://www.law.go.kr/
  - 영문 포털: https://www.law.go.kr/LSW/eng/engMain.do
  - 오픈 API / 공동활용: https://open.law.go.kr/
  - 운영기관(법제처): https://www.moleg.go.kr/

## 출처 표시

> 출처: 국가법령정보센터(법제처, https://www.law.go.kr) — 공공누리 제1유형(출처표시)에 따라 이용.

## 검증 한계

- 이 저장소의 실제 파일명 규칙과 예시 ID는 엔진 내 페처·테스트·픽스처로 확인할 수 없어(한국 전용 페처 없음) 명시하지 않았다.
- 국가법령정보센터는 법령 외에도 행정규칙, 자치법규, 조약, 판례 등을 제공하나, 본 저장소에 실제 포함된 문서 유형의 범위는 별도 확인이 필요하다.
