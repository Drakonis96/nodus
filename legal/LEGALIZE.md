# Legalize: reviewed sources and reuse obligations

Reviewed 2026-09-09. This register covers 32 public country/EU repositories.
The upstream country LICENSE and README are retained without modifications at
pinned commits. GitHub labels many of these licences `NOASSERTION`; that label
is not a grant or refusal. The actual per-country data clauses below govern.
The MIT licence of the index/pipeline does not replace them.

Project: [legalize-dev](https://github.com/legalize-dev), created by
[Enrique López](https://enriquelopez.eu). Additional credits: UK,
[Florin Ungur](https://github.com/florinungur); Korea,
[@9bow](https://github.com/9bow). MIT copyright: (c) 2026 Legalize; full
[notice](generated/LEGALIZE_MIT_LICENSE.txt) is shipped.

## Implementation obligations

- Each result and export carries the repository, authors, official source,
  country licence link, declared date/status, retrieval time and immutable SHA.
  Source metadata, including reuse/copyright fields, is preserved verbatim.
- Text is an unofficial automated reproduction, never a claim of official
  endorsement. Nodus identifies layout changes and optional article extraction;
  Legalize's Markdown conversion and omission of images are disclosed.
- Spain: the BOE derivative attribution, link to BOE, informative-consolidated
  notice and last-update metadata are retained. No logos or Digital Legal
  Library books are ingested by this adapter.
- CC BY 4.0 countries retain licensor/source, licence, date, notices and changes;
  no additional restrictions or AGPL relicensing are imposed on the data.
- France: Etalab 2.0 requires source and last-update attribution and prohibits
  misleading presentation. Norway: NLOD 2.0 requires Lovdata attribution,
  licence/source links and change disclosure. Uruguay: IMPO and the Uruguay
  open-data licence must be identified in the application and exports.
- UK: Crown/database rights, OGL v3 and the repository's contributors are
  acknowledged; the reuse notice also records Westlaw and EU-origin conditions.
  Korea: MOLEG/National Law Information Center, KOGL type 1, title/date/source
  and no endorsement. Colombia retains SUIN metadata and the official text.
- Public-domain statements apply to the identified official legislative texts,
  not to third-party marks or unrelated works. No pipeline, SDK, MCP server,
  executable or artwork is bundled or run. No private GitHub authentication.
- The application checks both upstream notice hashes on every request before
  reading current laws. A notice change or unknown country requires renewed
  review. It does not assume every future repository is licensed identically.

Official conditions additionally consulted:
[BOE](https://www.boe.es/informacion/aviso_legal/index.php),
[UK reuse](https://legislation.github.io/data-documentation/reuse-licence.html),
[NLOD 2.0](https://data.norge.no/nlod/en/2.0),
