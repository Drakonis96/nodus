# Auditoría de mutabilidad académica Desktop ↔ Server Web

Esta matriz separa capacidades que pueden operar sobre datos privados del usuario de las que exigirían modificar/publicar el snapshot del vault. El servidor no debe simular mutaciones públicas ni inventar datos ausentes.

| Superficie Desktop | Archivo/ruta Server Web | Dato consultado | Acción disponible en Server | Estado y límite seguro |
| --- | --- | --- | --- | --- |
| Biblioteca · lector | `src/serverWeb/LibraryServerView.tsx` · `/api/v1/spaces/:space/library/documents/:id`, `/api/v1/spaces/:space/personal-annotations` | Paquete Markdown/original publicado + anotaciones privadas de la cuenta | Leer, índice/progreso local, selección/subrayado/comentario, bookmark y estado leído/no leído | Implementado de forma segura. El estado de lectura usa el overlay privado con id determinista `reading-state-<documentId>` (localStorage sólo queda como fallback de dispositivo); nunca se escribe el manifiesto. Si sólo se publica el original, el lector arranca en esa versión; OCR, offsets y Zotero siguen siendo Desktop-only. |
| Deep Research · galería/lector | `src/serverWeb/PersonalViews.tsx` · `/view/deepResearch`, `/api/v1/spaces/:space/deep-research` | Informes publicados, imágenes, traducciones publicadas y traducciones privadas, anotaciones privadas | Leer, navegación por headings, subrayar/comentar, bookmark, marcar leído, guardar en notas, imprimir HTML y exportar PDF | Implementado. Las traducciones privadas se generan con un job, se guardan como artefactos propios y se seleccionan junto a las publicadas sin tocar el snapshot; el PDF binario también está disponible server-side. |
| Deep Research · generación | `src/serverWeb/PersonalViews.tsx` · `POST /api/v2/vaults/:space/ai/deep-research` + `POST /api/v2/me/artifacts` | Contexto publicado + resultado del job | Generar y guardar como artefacto `deep-research` privado | Implementado de forma aislada. No publica en `deep_research`; requiere credenciales AI del usuario. |
| Deep Research · regenerar/borrar/jobs | `src/serverWeb/api.ts` · `/api/v2/me/jobs/:id/*`, `/api/v2/me/artifacts/:id` | Job/artefacto/traducción propiedad del usuario | Crear, editar y eliminar informes/traducciones privadas; cancelar/reintentar jobs | Borrado privado seguro; la UI del informe permite cancelar/reintentar generación y las acciones permanecen limitadas a la cuenta autenticada. Nunca borra snapshot. |
| Estado de la cuestión · triple vista | `src/serverWeb/StateOfArtServerView.tsx` · `GET /state-of-art`, artifacts/jobs | Preguntas, debates, huecos publicados + preguntas/análisis privados | Pestañas, selección, filtros, enlaces al grafo/fuentes, anotación privada, CRUD de preguntas y análisis IA privados | Implementado con artifacts privados y contexto publicado. Las preguntas y análisis nunca entran en el snapshot; la IA requiere credenciales/modelo del usuario. |
| Workspace | `src/serverWeb/PersonalViews.tsx` · `/api/v2/me/artifacts` | Notas privadas + proyección publicada | Colecciones jerárquicas, notas/ideas, tags, pestañas, búsqueda, mover, papelera/restaurar/borrado definitivo, selección masiva y Markdown | Implementado sobre artifacts privados (`workspace-note`/`workspace-collection`) con metadata; la proyección publicada es solo lectura y nunca altera snapshot ni vault. |
| Escritura | `src/serverWeb/AcademicToolsServerView.tsx` · `/writing`, artifacts | Borradores publicados + borradores privados Markdown | Lista, detalle, Markdown, vista previa y CRUD privado | Implementado usando artifacts `workspace-note` con metadata `surface: writing`; aislado por cuenta y sin alterar publicaciones. Citas, selección de materiales, generación avanzada, versionado y exportación nativa siguen siendo Desktop. |
| Proyectos | `src/serverWeb/AcademicToolsServerView.tsx` · `/projects`, artifacts | Proyectos, secciones, capítulos y enlaces publicados + proyectos privados | Lista, detalle, Markdown, vista previa y CRUD privado | Implementado usando artifacts `workspace-note` con metadata `surface: project`; aislado por cuenta y sin publicar. Editor de capítulos, sugerencias/versiones, verificador y exportación nativa siguen siendo Desktop. |
| Exportación PDF binaria | `server/lib/routes/corpus.mjs` · `GET /deep-research/:id/document.pdf`; `server/lib/routes/artifacts.mjs` · `GET /api/v2/me/artifacts/:id/document.pdf` | Informe publicado o artefacto privado propio | PDF binario de texto con `pdf-lib`; la versión HTML maquetada sigue disponible para impresión | Implementado server-side sin ejecutar HTML ni cargar URLs remotas. El artefacto privado exige ownership y membresía del vault. |

## Verificación

- Las acciones privadas envían CSRF y están limitadas a la cuenta autenticada.
- El lector usa `POST /api/v1/spaces/:space/personal-annotations` para estado y anotaciones; el cierre de sesión usa el endpoint existente `POST /logout` con CSRF y no toca ningún vault.
- Los jobs usan el gateway existente y el contexto publicado; el resultado se guarda en `userArtifacts`.
- Las tablas docentes privadas (`groups`, `grades`, `assessment`) siguen fuera de toda colección pública.
