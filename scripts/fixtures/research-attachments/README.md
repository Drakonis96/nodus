# Synthetic Research chat fixtures

- `census.doc`: generated with macOS `textutil` from the text “Research attachment DOC fixture. Census total: 42. Madrid, año 1920.” Verifies the legacy OLE Word reader, not a renamed DOCX.
- `red-square.heic`: generated with macOS `sips` from a synthetic 80×60 solid-color PNG. Contains no personal photo or location information. Verifies actual HEVC decoding.

All other formats are generated by `scripts/test-research-attachments.mjs` in a temporary directory and removed after testing. Nothing from the user's vault or account is used.
